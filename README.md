# Análisis de Ventas TUP

## Descripción del Proyecto

Este proyecto fue realizado como trabajo práctico integrador utilizando herramientas de desarrollo y análisis de datos.

La idea principal fue trabajar con un archivo de ventas en formato CSV para obtener información útil, como el total vendido y el producto con mayor cantidad de ventas. Además, se utilizó Git y GitHub para llevar el control de versiones del proyecto y Jira para organizar las tareas.

## Funcionalidades

El programa permite:

* Leer información desde un archivo CSV
* Calcular el total de ventas
* Detectar cuál fue el producto más vendido
* Generar un gráfico con los resultados
* Guardar automáticamente el gráfico generado
